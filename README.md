## ✨ 核心特性

- 🚀 **极致轻量秒启 (仅 21MB)**：基于 C++20 与 Qt 6 原生开发，无重量级 Python 或体积膨胀，安装包从 96MB 骤降至 21MB，开机自启资源开销极小。
- 🖥️ **跨屏与全景快照**：完整支持多显示器、异构 DPI、负坐标虚拟桌面拼接，彻底解决多屏截取偏移与模糊问题。
- 📜 **滚轮辅助长截图 (新)**：纯原生全重叠 MSE 像素级自适应缝合，支持选区鼠标直接穿透滚动网页与代码，1:1 物理像素完美缝合，彻底消除黑条与重复切片。
- 🎬 **所见即所得 GIF 动态录屏 (新)**：内置轻量高效多帧 GIF89a 变长 LZW 录屏引擎，支持选区红框高亮、实时计时录制与自定义导出。
- 🧩 **可插拔插件中心 (新)**：Word 经典功能区 Ribbon 布局，支持 RapidOCR 离线文字识别、Mozilla Bergamot 离线机器翻译一键下载与本地 ZIP 导入。
- 🌐 **双轨智能机器翻译系统 (新)**：
  - **国内高速在线通道**：免 Key、免注册、零梯子直连，多通道自动容灾热备；
  - **纯本地离线翻译**：集成 Mozilla Bergamot / MarianMT 架构与本地大模型（Ollama / Qwen / DeepSeek）通用端点，0 联网隐私保护。
- 📌 **独立置顶贴图 (3D 立体落影)**：一键将截图转化为独立置顶窗口（`F3`），配备 16px 多层柔和落影与科技蓝悬浮外框，截取与桌面同色也能一眼看清边界。
- 🔍 **OCR 双引擎与同图 0ms 秒切**：支持 Windows 原生 WinRT OCR 与 RapidOCR 深度引擎，同张截图引擎切换 0 毫秒瞬间恢复，彻底消除重复识别。
- 🎨 **丰富矢量标注与单字符修图**：支持矩形、箭头、画笔、马赛克及就地富文本输入（修正回车文字上浮 Bug），支持单字符涂抹原位替换。
- 🌗 **跟随系统深浅色主题**：自动感知 Windows 10/11 的深色/浅色应用配色，工具栏、托盘与设置面板自适应 Fluent 风格。
- ⚙️ **开机自启动支持**：设置中新增开机自启开关，首次运行默认开启，静默常驻托盘随时准备截屏。

## 📖 核心功能使用指南

### 1. 🧩 插件中心 (扩展商城) 使用方法
为了让主程序保持 21MB 的极致轻量身材，重量级离线模型（如 RapidOCR 文字识别库、Bergamot 离线翻译）采用独立扩展包管理：
1. 右键任务栏右下角 Evan 图标，点击 **`🧩 插件中心...`**；
2. **在线一键安装**：点击目标插件右侧的 **`[📥 一键安装]`**，系统将通过国内高速 CDN 镜像加速下载并自动解压部署，无需重启软件即刻热生效；
3. **本地 ZIP 导入**：若从网盘或他人处获取了插件压缩包，点击顶部的 **`[📦 本地导入 ZIP]`**，选取 `.zip` 文件即可自动导入解压识别；
4. **插件卸载**：已安装插件点击 **`[🗑️ 卸载]`** 即可安全清理模型文件并释放磁盘空间。

### 2. 📜 滚轮辅助长截图使用方法
长截图采用创新的鼠标穿透机制，无需复杂的自动化注入，手感顺滑如丝：
1. 按下 **`F1`** 唤起截屏，拖拽框选您想要截取的网页或文档视口宽度；
2. 点击工具栏上的 **`📜` (长截图)** 按钮；
3. 全屏暗色遮罩自动隐去，浮现蓝色视口边框与控制胶囊；
4. **在选区内正常向下滚动鼠标滚轮**：底层的浏览器或文档自然向下滚动，控制胶囊实时显示已拼接高度（如 `高度: 1820px (6帧)`）；
5. 滚动到目标位置后，点击胶囊上的 **`[ 保存 ]`** 即可选择目录存盘为 PNG、GIF、JPG、WebP，长图亦自动同步至剪贴板！点击 **`[ 取消 ]`** 可随时安全退出。

### 3. 🎬 GIF 动态高帧率录屏使用方法
1. 按下 **`F1`** 框选需要录制动图的屏幕区域；
2. 点击工具栏上的 **`🎬` (GIF 录屏)** 按钮；
3. 选区四周显示红黄虚线录制框，下方弹出控制栏；
4. 点击 **`[ 开始录制 ]`**，计时器启动，您可以在选区内自由操作软件或播放动画；
5. 录制完毕后，点击 **`[ 停止并保存 ]`**，选择保存路径即可导出高质量动图 `.gif` 文件。

### 4. 🌐 双轨翻译与全自动联动
1. 截取文字并按 **`O`**（或点击放大镜）弹出识别窗口；
2. 翻译模式下拉框支持自由切换：
   - **`在线直连 (国内高速)`**：国内专线直连，中译英、中译日毫秒级出字，免 Key 免配置；
   - **`离线插件 (纯本地)`**：纯本地运算，支持 Mozilla Bergamot 神经翻译或自动直连本地 Ollama (Qwen/DeepSeek) 大模型，0 联网请求，隐私绝对安全；
3. **全自动即时翻译**：切换语言方向（如 `中文 ➔ 英语`、`中文 ➔ 日语`）或切换模式时，系统全自动触发翻译上屏，耗时在底部以浅灰小字优雅展示。

## 📝 版本更新日志 (Changelog)

### v1.1.1 (2026-10-10)
- **长截图核心重构**：
  - 深度排查并解决了高 DPI 屏幕下 DPR 缩放导致画布边缘产生透明未绘制黑条的漏洞，强制按 1:1 物理像素绘制拼接，黑条彻底清零；
  - 引入全重叠区域均方误差（Full Overlap MSE）对齐算法，彻底解决 B站深色模式等暗黑背景下的误位移与切片重复问题；
  - 控制胶囊精简为纯文本 `[ 保存 ]` 与 `[ 取消 ]`，去除冗余图标；
  - 选区边框采用 100% 鼠标穿透技术（`WA_TransparentForMouseEvents`），滚轮顺畅驱动底层浏览器/文档正常滚动。
- **GIF 动态录屏**：
  - 打造所见即所得全可视化录制交互，解决此前后台静默录屏造成的“选区消失、鼠标转圈”盲盒困扰；
  - 界面极简整齐：就绪态显示 `[ 开始录制 ]`、录制中显示 `[ 停止并保存 ]` 与实时计时器；
  - 纯原生多帧 GIF89a 变长 LZW 视频流编码，零重型第三方依赖。
- **贴图 3D 立体落影**：
  - 预留 16px 多层柔和立体落影与科技蓝悬浮外框，截取与桌面 100% 相同底色也能一眼清晰辨识贴图边界。
- **文字标注修复**：
  - 修正了文字标注在按下 Enter 提交时基线垂直偏移，文字与输入框 1:1 像素级完全重合，绝不上浮跳动。

### v1.1.0 (2026-10-09)
- **安装包体积锐减 77%**：引入轻量可插拔插件中心（Plugin Market），将 AI 离线模型与主程序彻底解耦，安装包从 96MB 骤降至 21.46MB；
- **核心插件分发**：支持 RapidOCR 离线文字识别引擎与 Mozilla Bergamot 离线翻译模型一键下载与本地 ZIP 导入；
- **智能双轨翻译**：
  - 在线直连升级为国内免梯子高速通道，加入请求防抖与 Google GTX 自动容灾热备；
  - 离线翻译支持 Mozilla Bergamot / MarianMT 架构与本地离线大模型（Ollama / Qwen / DeepSeek）通用端点；
  - 解决离线中译英输出仍是中文或出现 `[char]` 的缺陷，支持全语种双向流式翻译；
- **OCR 体验升级**：
  - OCR 引擎与翻译模式全面规范为下拉框交互，拓宽宽度避免文字遮挡；
  - 引入同图识别结果缓存池（`m_engineResultCache`），不同引擎之间切换 0 毫秒秒切，彻底消除重复识别；
- **全项目 Logo 换新**：全量换用全新专属 Logo，生成覆盖全规格的 Windows 原生 `app.ico` 与高清 PNG 图标。

## 🛠️ 构建与编译指南

### 环境依赖
- **操作系统**：Windows 10 1809 及以上 / Windows 11 (x64)
- **编译器**：MSVC 2022 (支持 C++20)
- **构建工具**：CMake 3.20+、Ninja
- **依赖库**：Qt 6 (Core, Gui, Widgets, Network)

### 本地编译命令
```bash
# 初始化构建目录
mkdir build && cd build

# CMake 生成工程 (根据本地环境指定 Qt6 安装路径)
cmake .. -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DQt6_DIR="E:/Qt/6.8.3/msvc2022_64/lib/cmake/Qt6"

# 执行编译构建
ninja
```
