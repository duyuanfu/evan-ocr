## ✨ 核心特性

- 🚀 **极致轻量秒启 (仅 21MB)**：基于 C++20 与 Qt 6 原生开发，无重量级 Python 或体积膨胀，安装包从 96MB 骤降至 21MB，开机自启资源开销极小。
- 🖥️ **跨屏与全景快照**：完整支持多显示器、异构 DPI、负坐标虚拟桌面拼接，彻底解决多屏截取偏移与模糊问题。
- ⛶ **一键全屏截图 (新增)**：按下 `F2` 即可无选区直接捕获整个虚拟桌面（自动含所有显示器）并复制到剪贴板。
- 💾 **自定义保存路径与自动记忆 (新增)**：可指定固定截图保存目录，并自动记忆最近一次保存位置，下次打开即定位。
- 📜 **滚轮辅助长截图 (新)**：纯原生全重叠 MSE 像素级自适应缝合，支持选区鼠标直接穿透滚动网页与代码，1:1 物理像素完美缝合，彻底消除黑条与重复切片。
- 🎬 **所见即所得 GIF 动态录屏 (新)**：内置轻量高效多帧 GIF89a 变长 LZW 录屏引擎，支持选区红框高亮、实时计时录制与自定义导出。
- 🧩 **可插拔插件中心 (新)**：Word 经典功能区 Ribbon 布局，支持 RapidOCR 离线文字识别、Mozilla Bergamot 离线机器翻译一键下载与本地 ZIP 导入。
- 🌐 **双轨智能机器翻译系统 (新)**：
  - **国内高速在线通道**：免 Key、免注册、零梯子直连，多通道自动容灾热备；
  - **纯本地离线翻译**：集成 Mozilla Bergamot / MarianMT 架构与本地大模型（Ollama / Qwen / DeepSeek）通用端点，0 联网隐私保护。
- 📌 **独立置顶贴图 (3D 立体落影)**：一键将截图转化为独立置顶窗口（`F3`），配备 16px 多层柔和落影与科技蓝悬浮外框，截取与桌面同色也能一眼看清边界。
- 🔍 **OCR 双引擎与同图 0ms 秒切**：支持 Windows 原生 WinRT OCR 与 RapidOCR 深度引擎，同张截图引擎切换 0 毫秒瞬间恢复，彻底消除重复识别。
- ∑ **数学公式识别与转换 (新)**：截屏工具栏专属 `∑` 按钮，支持复杂二维数学公式一键提取为 LaTeX 源码、块级 Markdown 及 **MathML (Word 原生公式 Ctrl+V 直粘)**，双轨支持免安装云端高速通道与本地离线插件。
- 🎨 **丰富矢量标注与单字符修图**：支持矩形、箭头、画笔、马赛克及就地富文本输入（修正回车文字上浮 Bug），支持单字符涂抹原位替换。
- 🌗 **跟随系统深浅色主题**：自动感知 Windows 10/11 的深色/浅色应用配色，工具栏、托盘与**全部弹窗（含系统原生标题栏）**自适应 Fluent 风格。
- ⚙️ **开机自启动支持**：设置中新增开机自启开关，首次运行默认开启，静默常驻托盘随时准备截屏。

## 📥 下载与安装指南

### 第一步：下载主程序（Windows 便携版）

前往 **Releases 页面**下载最新版本的绿色便携包：

> 🔗 **主程序下载页**：<https://github.com/duyuanfu/evan-ocr/releases>

- 找到标记为 **Latest** 的版本条目；
- 在 **Assets（附件）** 区域点击下载 **`evan-v1.2.0-windows-x64.zip`**（约 21MB）；
- 下载完成后 **解压即用**，双击 `evan.exe` 即可运行，**无需安装、无需管理员权限、无任何捆绑**。

### 第二步：按需下载离线插件包（可选但强烈推荐）

重量级的离线 AI 模型（RapidOCR 文字识别 / Bergamot 离线翻译 / RapidLaTeXOCR 公式引擎）体积较大，单独打包为可选扩展，不会拖慢主程序启动：

> 🔗 **插件包专用下载页**：<https://github.com/duyuanfu/evan-ocr/releases#release-plugins>

- 打开上链接后，**向下滚动到 `Plugins` 区域**（锚点会自动跳转到该区块）；
- 在该区域下载所需插件压缩包：
  - `evan-plugin-rapidocr-engine.zip` — 离线高精度文字识别引擎（~74MB）
  - `evan-plugin-translation-en-zh.zip` — 离线中英神经翻译模型（~38MB）
  - `evan-plugin-latex-ocr.zip` — 离线数学公式识别引擎（~178MB）
  - `evan-plugin-gif-recorder.zip` — GIF 动态录屏扩展（~15MB）
- 下载完成后，回到软件内按下方 **「插件中心」使用指南** 中的「方式一：软件内一键本地导入」完成安装。

### 第三步：安装完成 ✅

- 右键点击桌面右下角 **系统托盘** 中的 Evan 图标，即可看到完整功能菜单；
- 首次运行会自动开启 **开机自启**（如需关闭请进入 `⚙️ 设置` 取消勾选）。

## 📖 核心功能使用指南

### 1. 🖼️ 基础截图：区域截取与全屏捕获

#### 方式一：区域截图（最常用）
1. 按下 **`F1`**（可自定义）唤起全屏暗色遮罩与取色放大镜；
2. **按住鼠标左键拖拽**，框选想要截取的区域，松开即完成选区；
3. 选区四角出现 **可拖拽的控制手柄**，可随时微调选区大小；
4. 此时浮动工具栏已就绪，可继续做标注、OCR、翻译、保存等操作；
5. 按 **`Enter`** 完成截图 → 图片自动复制到系统剪贴板；或按 **`Ctrl+S`** 另存为文件。

#### 方式二：一键全屏截图（新增）
1. 按下 **`F2`**（可自定义）；
2. **无需任何选区操作**，整个虚拟桌面（自动包含所有显示器）立即被完整捕捉并复制到剪贴板；
3. 适合快速保存整个工作区、多屏拼接画面或用作临时壁纸素材。

> 💡 提示：在系统托盘菜单中也有「一键全屏截图 (F2)」入口，鼠标点击即可触发。

#### 方式三：滚轮辅助长截图
长截图采用创新的鼠标穿透机制，无需复杂的自动化注入，手感顺滑如丝：
1. 按下 **`F1`** 唤起截屏，拖拽框选您想要截取的网页或文档**视口宽度**；
2. 点击工具栏上的 **`📜` (长截图)** 按钮；
3. 全屏暗色遮罩自动隐去，浮现蓝色视口边框与控制胶囊；
4. **在选区内正常向下滚动鼠标滚轮**：底层的浏览器或文档自然向下滚动，控制胶囊实时显示已拼接高度（如 `高度: 1820px (6帧)`）；
5. 滚动到目标位置后，点击胶囊上的 **`[ 保存 ]`** 即可选择目录存盘为 PNG、GIF、JPG、WebP，长图亦自动同步至剪贴板！点击 **`[ 取消 ]`** 可随时安全退出。

#### 方式四：GIF 动态高帧率录屏
1. 按下 **`F1`** 框选需要录制动图的屏幕区域；
2. 点击工具栏上的 **`🎬` (GIF 录屏)** 按钮；
3. 选区四周显示红黄虚线录制框，下方弹出控制栏；
4. 点击 **`[ 开始录制 ]`**，计时器启动，您可以在选区内自由操作软件或播放动画；
5. 录制完毕后，点击 **`[ 停止并保存 ]`**，选择保存路径即可导出高质量动图 `.gif` 文件。

#### 方式五：独立置顶贴图（3D 立体落影）
1. 在截屏选区状态下按 **`F3`**（或点击工具栏 `📌`），或直接按 **`F3`** 将**剪贴板中的图片**贴图；
2. 图片立即变为独立置顶窗口，配备 16px 多层柔和落影与科技蓝悬浮外框；
3. 支持 **`滚轮`** 以鼠标为中心等比缩放、**`Ctrl + 滚轮`** 调节 10%~100% 透明度、**右键** 呼出菜单（识别文字 / 复制 / 保存 / 关闭）。

### 2. ✏️ 矢量标注与单字符修图

在截图选区建立后，浮动工具栏提供全套矢量标注能力：

| 工具 | 快捷键 | 使用方式 |
| :--- | :---: | :--- |
| 矩形框 | `R` | 拖拽绘制空心/实心矩形，可用于高亮重点或打码边框 |
| 箭头 | `A` | 拖拽绘制指示箭头，指向关键信息 |
| 自由画笔 | `P` | 自由涂鸦笔迹，用于圈画与手写批注 |
| 文字 | `T` | 就地点击输入富文本，**支持多行排版**，逐行基线 1:1 像素级精准对齐 |
| 马赛克 | `M` | 拖拽涂抹局部打码遮罩，敏感信息一键脱敏 |
| 单字修改 | `E` | 单字符原位替换（如把错别字改成正确字），笔迹自动融合背景 |
| 撤销 | `Ctrl+Z` | 撤销最近一次绘制的图元标注 |

- **文字回车规则可自定义**：设置面板中可切换 `Enter 提交 / Shift+Enter 换行`（默认）或 `Ctrl+Enter 提交 / Enter 换行`。
- 标注完成后按 **`Enter`** 即可将「原图 + 全部标注」合成结果复制到剪贴板。

### 3. 🔍 OCR 文字识别与双轨翻译

1. 截取文字区域后按 **`Ctrl+O`**（或点击工具栏 `🔍`）弹出文字识别工作台；
2. 左侧为**原图对照**（可开关文字定位框），右侧为**提取结果**；
3. 顶部下拉框可自由切换 **OCR 引擎**：
   - **`RapidOCR (离线)`** — 深度离线引擎，精度更高（需在插件中心安装对应扩展包）；
   - **`Windows 原生`** — 系统内置 WinRT OCR，零依赖开箱即用；
   - 同一张图的识别结果会被缓存，**引擎切换 0 毫秒秒切**，绝不重复识别。
4. 内嵌「译文对照」面板，翻译模式下拉框支持：
   - **`在线直连 (国内高速)`** — 国内专线直连，中译英/中译日毫秒级出字，免 Key 免配置；
   - **`离线插件 (纯本地)`** — 纯本地运算，支持 Mozilla Bergamot 神经翻译或自动直连本地 Ollama (Qwen/DeepSeek) 大模型，0 联网请求，隐私绝对安全；
5. 切换语言方向（如 `中文 ➔ 英语`、`中文 ➔ 日语`）或切换模式时，系统**全自动触发翻译上屏**，耗时在底部以浅灰小字优雅展示。

### 4. ∑ 数学公式识别与 Word/Markdown 转换

1. 按下 **`F1`** 框选包含数学公式、物理公式或化学结构的屏幕区域；
2. 点击工具栏上的 **`∑` (公式识别)** 独立按钮；
3. 弹出专属公式工作台，左侧原图与右侧 **300 DPI 高清矢量渲染图**同屏对比校对；
4. **一键多格式导出**：
   - **`[ 复制 LaTeX ]`**：直接用于 Overleaf、LaTeX 论文写作与排版；
   - **`[ 复制 Markdown ]`**：自动包裹块级 `$$ ... $$` 语法，完美适配 Obsidian、Notion 与 Typora；
   - **`[ 复制 Word (MathML) ]` (杀手级体验)**：将标准 MathML XML 写入剪贴板，切换至 **Microsoft Word** 直接按 **`Ctrl+V`**，瞬间全自动转化为原生的 Word 可编辑矢量数学公式对象（OMML）！
5. **双轨容灾热备**：默认采用毫秒级免安装模型的云端通道；断网时可随时平滑降级至本地 `RapidLaTeXOCR` 独立离线插件。
6. 如需云端授权加速，可在公式工作台点击 **`⚙️ 配置 Token`**，前往 [simpletex.cn](https://simpletex.cn) 免费申请（每月赠送上千次调用）。

### 5. 🧩 插件中心 (扩展商城) 使用方法与离线安装指南

为了让主程序保持约 21MB 的极致轻量身材，重量级离线 AI 模型（如 RapidOCR 文字识别库、Bergamot 离线翻译、RapidLaTeXOCR 公式引擎）采用独立扩展包管理。

#### 方式一：软件内一键本地导入 (推荐·最简单)
1. 从 [插件包专用下载页](https://github.com/duyuanfu/evan-ocr/releases#release-plugins) 下载对应的插件压缩包（如 `evan-plugin-latex-ocr.zip` 或 `evan-plugin-rapidocr-engine.zip`）；
2. 启动 Evan，右键桌面右下角托盘图标，点击 **`🧩 插件中心...`**；
3. 点击窗口顶部的 **`[ 本地导入 ZIP ]`**，选取刚下载的 `.zip` 压缩文件；
4. 系统将全自动完成解压部署与就绪校验，**无需重启软件即刻热生效**！

#### 方式二：手动绿色解压部署
1. 进入 Evan 软件所在的根目录，找到 `plugins/` 文件夹（若无则新建一个）；
2. 将下载的压缩包直接解压到 `plugins/` 目录下：
   - 支持解压为标准命名目录（如 `plugins/latex_ocr/` 或 `plugins/ocr/`）；
   - 也支持解压为带包名目录（如 `plugins/evan-plugin-latex-ocr/`）；
3. Evan 启动时内置多层级智能递归扫描器，会自动探测到模型文件并显示为「已安装并就绪」。

#### 方式三：在线一键下载安装
- 在插件中心点击目标插件右侧的 **`[ 一键安装 ]`**，系统将通过高速 CDN 镜像加速下载并自动解压部署。

#### 插件卸载
- 已安装插件点击 **`[ 🗑️ 卸载 ]`** 即可安全清理模型文件并释放磁盘空间。

### 6. 💾 自定义保存路径与自动记忆上次位置

- 打开 **`⚙️ 设置`** → 常规设置 → **`💾 自定义保存文件路径`** 卡片；
- 点击 **`浏览…`** 选择您习惯的保存目录（例如 `D:\Screenshots`），所有截图 / 长截图 / 贴图 / GIF 的保存动作都会默认落到该目录；
- 点击 **`清除`** 可恢复为系统默认（Windows 图片目录）；
- 勾选 **`自动记忆上次保存位置`** 后，软件会自动记住最近一次成功保存的所在目录，下次打开保存对话框时**自动定位**，无需每次重新翻找。

### 7. 🌐 网络代理设置（下载加速 / 内网环境）

- 打开 **`⚙️ 设置`** → 常规设置 → **`🌐 全局网络代理设置`** 卡片；
- 三种模式任选其一：
  - **`跟随系统代理 (默认)`** — 沿用 Windows 系统代理设置；
  - **`自定义代理服务器`** — 支持 HTTP 与 SOCKS5 协议，可直接粘贴 `http://127.0.0.1:7890` 之类的地址，系统会自动识别并填入主机与端口；
  - **`直连 (不使用代理)`** — 完全绕过任何代理直连。
- 点击 **`测试连接`** 可立即验证代理连通性并查看毫秒级延迟；
- 该设置**全局生效**，统一接管版本检查、升级包下载、插件中心扩展安装与公式云端识别通道。

### 8. 🔄 软件内一键检查更新与自动升级

- 托盘右键菜单点击 **`🔄 检查更新...`**，或在设置面板中点击 **`检查更新`**；
- 软件启动时也会在后台**静默检查**新版本（可在设置中关闭）；
- 发现新版时弹出专属升级工作台，展示**更新日志**、**下载进度**与**实时下载速度**；
- 点击 **`立即一键更新`** 后，软件会自动：下载 → 校验 → 等旧进程退出 → 覆盖替换程序文件 → **自动保护本地 `plugins/` 插件与模型库** → 重启拉起新版本。

### 9. 🎨 界面与主题

- **`⚙️ 设置`** → 常规设置 → **`🎨 主题外观风格`**：可选择「跟随 Windows 系统设置 / 明亮浅色模式 / 沉浸深色模式」；
- 深色模式下，**所有弹窗（含系统原生标题栏、插件中心、OCR 工作台、公式工作台、升级工作台）**均完整适配沉浸暗色 Fluent 风格；
- 4K / High DPI 屏幕下全局启用次像素抗锯齿，文字与图标边缘锐利无毛刺。

## 🛠️ 构建与编译指南

### 环境依赖
- **操作系统**：Windows 10 1809 及以上 / Windows 11 (x64)
- **编译器**：MSVC 2022 (支持 C++20)
- **构建工具**：CMake 3.20+、Ninja
- **依赖库**：Qt 6 (Core, Gui, Widgets, Network)

### 本地编译命令
```bash
# 初始化构建目录
mkdir build && cd build

# CMake 生成工程 (根据本地环境指定 Qt6 安装路径)
cmake .. -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DQt6_DIR="E:/Qt/6.8.3/msvc2022_64/lib/cmake/Qt6"

# 执行编译构建
ninja
```
