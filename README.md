## ✨ 核心特性

- 🚀 **毫秒级极速响应**：基于 C++20 与 Qt 6 原生开发，无重量级运行时依赖，开机自启资源开销极小。
- 🖥️ **跨屏与全景快照**：完整支持多显示器、异构 DPI、负坐标虚拟桌面拼接，彻底解决多屏截取偏移与模糊问题。
- 🌗 **跟随系统深浅色主题**：自动感知 Windows 10/11 的深色/浅色应用配色，工具栏、托盘与设置面板自适应 Fluent 风格，长时间使用低对比不伤眼。
- 📦 **多格式导出 (新增 WebP)**：支持保存为 WebP、PNG、JPEG、BMP 格式，WebP 同画质下体积减少约 30%~70%，极利于存储与网络分发。
- 🎯 **智能边缘与元素吸附 (可开关)**：精准检测窗口轮廓、控件区域与文本段落，按 `Tab` 循环切换候选框；可在偏好设置中自由开启或关闭。
- 🎨 **丰富矢量标注**：支持矩形、箭头、自由画笔、马赛克打码及原地所见即所得富文本输入，支持全功能撤销（`Ctrl+Z`）。
- 📌 **独立置顶贴图**：一键将截图转化为独立置顶窗口（`F3`），支持平滑缩放、透明度滚轮调节、拖拽与复制。
- 🔍 **原生无依赖 OCR**：内嵌 Windows 10/11 原生 WinRT OCR 引擎，无需联网、无需下载庞大模型权重，毫秒级提取文本与字符包围盒。
- ⌨️ **全功能快捷键配置**：全局热键、截屏交互、标注工具、贴图窗口快捷键均支持可视化录制与冲突校验。

## 📦 安装与使用指南

### 方式一：绿色解压即用（推荐）

1. 前往 [Releases 发行版页面](https://github.com/duyuanfu/evan-ocr/releases) 下载最新版免安装压缩包（例如 `evan-v1.0.0-windows-x64.zip`）；
2. 解压至本地任意路径（建议尽量避免含特殊字符的路径，如 `D:\Tools\Evan\`）；
3. 进入文件夹，直接双击 **`evan.exe`** 即可启动；
4. 启动后程序会自动常驻于 Windows 任务栏右下角系统托盘：
   - 按下 **`F1`** 即可立即唤醒全屏截屏与放大镜；
   - 按下 **`F3`** 可将当前剪贴板内的图像直接作为置顶贴图呈现在屏幕上；
   - 右键点击托盘图标可进行 **⚙️ 快捷键设置** 或退出程序。

### 方式二：配置开机静默自启动（可选）

如需每次开机自动启动 Evan：
1. 在键盘上同时按下 **`Win + R`** 打开运行窗口，输入 **`shell:startup`** 并回车，进入系统的“自启动文件夹”；
2. 右键 `evan.exe`，选择“创建快捷方式”；
3. 将生成的快捷方式剪切或复制到刚打开的自启动文件夹中即可。

### 💡 系统 OCR 语言包要求提示

Evan 采用 Windows 操作系统内置的 WinRT OCR 引擎，具备零依赖、启动飞快的优势：
- 识别中文简体：请确保 Windows **设置 -> 时间和语言 -> 语言** 中已包含“中文（简体，中国）”，且系统组件中包含 OCR 识别包（Windows 10/11 通常默认已内置）；
- 识别英文、日文、韩文等其他语种：可直接在 Windows 系统语言设置中添加对应语种即可自动生效，完全无需额外下载第三方模型。

### 🚀 OCR 双引擎架构与 RapidOCR 高精度扩展 (方案 A)

Evan 采用了开放可插拔的双 OCR 引擎架构：

1. **内置引擎：Windows 原生 WinRT OCR（免安装，开箱即用）**：
   - 零额外体积依赖，毫秒级冷启动；
   - 内置简体中文语言包优先命中与自适应双三次插值超分辨率技术，小字识别清晰。
2. **高精度引擎：RapidOCR / PaddleOCR（推荐进阶）**：
   - 国内准确度极高的开源 OCR 方案，中英、数字、标点符号、手写体识别率高达 98%+；
   - **开启方法**：
     只需在程序所在目录新建 `rapidocr/` 文件夹，将 [RapidOCR-json](https://github.com/RapidAI/RapidOCR) 运行程序（`RapidOCR-json.exe`）及 PP-OCR 模型文件放置在 `rapidocr/` 内；
     Evan 将会自动检测并无缝升级至 RapidOCR 高精引擎！
   - **一键切换**：在 OCR 对比结果弹窗中点击 **`🔄 切换引擎`** 按钮，即可随时在两大引擎之间无缝切换并即时重新识别。

## ⌨️ 常用快捷键一览

快捷键可在托盘菜单中选择 **⚙️ 快捷键设置** 随时按需自定义：

| 场景 | 功能操作 | 默认快捷键 | 说明 |
| :--- | :--- | :---: | :--- |
| **全局** | 开始截屏 | `F1` | 随时唤醒全景截屏遮罩与取色放大镜 |
| **全局** | 桌面贴图 | `F3` | 截屏时贴图选区 / 选区外直接将剪贴板图像贴图 |
| **截屏** | 撤销上一步 | `Ctrl+Z` | 撤销最近一次绘制的图元标注 |
| **截屏** | 选区贴图 | `F3` | 将当前截图转为置顶贴图窗口 |
| **截屏** | 完成截屏 | `Enter` / `Return` | 复制截图到位图剪贴板并退出遮罩 |
| **截屏** | 保存到文件 | `Ctrl+S` | 快速另存为 PNG/JPG/BMP 图像 |
| **截屏** | 提取文字 (OCR) | `Ctrl+O` | 识别选区内容并在对比窗中展示 |
| **截屏** | 取消截屏 | `Esc` | 放弃当前截屏 |
| **截屏** | 工具切换 | `R` / `A` / `P` / `T` / `M` | 快捷激活 矩形/箭头/画笔/文字/马赛克 |
| **贴图** | 识别图中文字 | `Ctrl+O` | 对当前贴图进行 OCR 文字提取 |
| **贴图** | 复制贴图 | `Ctrl+C` | 复制贴图至剪贴板 |
| **贴图** | 保存贴图 | `Ctrl+S` | 另存为图片文件 |
| **贴图** | 调节透明度 | `Ctrl + 滚轮` | 10% ~ 100% 动态透明度调节 |
| **贴图** | 等比缩放 | `滚轮` | 以鼠标为中心平滑缩放 |
| **贴图** | 关闭贴图 | `Esc` / 双击 | 销毁并关闭贴图窗口 |

## 🛠️ 构建与编译指南

### 环境依赖

- **操作系统**：Windows 10 1809 及以上 / Windows 11 (x64)
- **编译器**：MSVC 2022 (支持 C++20)
- **构建工具**：CMake 3.20+、Ninja
- **依赖库**：Qt 6 (Core, Gui, Widgets)

### 本地编译命令

```bash
# 初始化构建目录
mkdir build && cd build

# CMake 生成工程 (根据本地环境指定 Qt6 安装路径)
cmake .. -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DQt6_DIR="E:/Qt/6.8.3/msvc2022_64/lib/cmake/Qt6"

# 执行编译构建
ninja
```
