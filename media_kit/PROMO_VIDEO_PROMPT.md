```markdown
# Role: 高级全栈视频生成工程师与数码区顶级视频编导

你是一个精通 Python 图形渲染（PIL）、音视频处理（FFmpeg）与短视频营销的专家。
现在需要为开源/独立软件项目【项目名称：XXXXX】制作一段面向 B 站（或短视频平台）的高品质 1080P 产品介绍与宣传视频。

- 项目名称：[填入你的项目名称，如：EvanOCR]

  2. [卖点2：如：独家左右分栏 1:1 对照排版与汉字空格消除]
  3. [卖点3：如：丝滑矢量标注与置顶贴图随时二次 OCR]

## 二、 视频硬性指标（必须严格遵循）
1. **画质与规格**：1920×1080 分辨率，30 FPS 或 60 FPS，编码器使用 `libx264` + `aac`，像素格式 `yuv420p`，开启 `-movflags +faststart`。
2. **节奏控制（黄金完播率法则）**：
   - 全片时长严格控制在 **30~45 秒以内**；
   - 包含 6~7 个分镜，**每个分镜（一帧）时长严禁超过 5 秒**；
   - 句意紧凑，语速快节奏，绝不拖泥带水。
3. **视觉美学规范（杜绝压抑黑底与两边太空）**：
   - **背景风格**：彻底摒弃传统压抑的黑色背景，采用现代极简、大气通透的 **浅灰蓝/暖白（Fluent / macOS Light 风格）渐变底色 + 浅色微点阵网格**。
   - **内容宽幅撑满**：卡片或实机窗口宽度必须达到 **1680px ~ 1720px**（左右各留 100px 呼吸边距），彻底杜绝画面左右两侧太空旷的问题。
   - **文字排版与防溢出**：主标题 52~64px 粗体，副标题 28~32px，卡片标题 32px，正文 22~26px。**所有文本必须提前计算像素宽度，精炼文案，严禁任何一行文字溢出卡片边框**。
   - **杜绝字符方块缺字**：工具栏图标、符号、彩色色盘**严禁依赖易缺字的 Unicode 符号或 Emoji**，必须全部采用 **PIL 原生矢量形状绘制**（如 `rounded_rectangle` 矩形、`line`+`polygon` 箭头、`ellipse` 调色板真实填色圆点等），保证 100% 清晰且永不缺字。
   - **视觉动态**：加入动态激光扫描线往复平滑移动、卡片入场缓入位移、呼吸高光等微动画，赋予画面生命力。
4. **第一帧黄金法则（完播率钩子）**：
   - 第一帧必须极其华丽吸睛，配有 200px+ 超清应用大图标、动态呼吸彩色科技光晕、高光徽章，直接点出颠覆痛点的大标题，牢牢留住前 3 秒的用户。
5. **音频与音字严格同步**：
   - **真人感解说**：使用 `edge-tts` 库，选用微软超拟真活力男声 `zh-CN-YunxiNeural`，配置 `rate='+20%'` 或 `'+25%'`，充满年轻 UP 主的自然活力，杜绝机械电音。
   - **音字毫秒级同步**：采用**逐句独立生成音频并在精确时间轴上切片渲染**的架构，确保字幕每句话与当前发音毫秒级对应，**严禁使用遮挡视线的黑底矩形字幕框**，采用纯净高对比度文字加柔和投影。
   - **真实背景音乐**：自动下载或混入欢快舒适的轻量科技 Lo-Fi / 电子 BGM，音量精确衰减至 0.07~0.08，绝不压盖人声。
6. **工程归档要求**：
   - 所有生成的音视频文件、WAV 片段、BGM、Python 渲染脚本统一存放在独立专有目录（如 `media_kit/`），保持主工程根目录整洁。

## 三、 执行要求
请直接编写一个全自动、自包含的 Python 自动化流水线脚本（如 `build_promo_video.py`），脚本能够自动完成：
1. 创建 `media_kit/` 目录；
2. 逐句调用 `edge_tts` 生成超自然语音并获取精确时长（每句严格限制在 3.5~4.8 秒）；
3. 合并音轨并与背景配乐混音；
4. 利用 Python PIL 渲染高质感浅色宽屏 1080P 画面帧；
5. 管道对接本地 FFmpeg 进行 H.264 硬件加速压制，输出最终成品 MP4；
6. 自动执行该脚本完成成片交付，并附赠针对 B 站的 3 组爆款标题、详尽简介、热门标签及置顶评论模板。
```
