## Context

用户在截屏后经常需要对截图画面中的局部文本、数字或字母进行轻度篡改、更正或遮盖替换（如修改报表某位金额、隐藏证件号某几位、修正截图错别字）。此前尝试的全行整段替换方案由于粒度过粗，容易导致字间距累积偏差、邻近文字被误伤擦除等问题。
本设计聚焦于**单字符级别（Character-Level）的原地识别、微创背景修补与高精对齐编辑**，提供极致友好、轻量自然的单字修改体验。

## Goals / Non-Goals

**Goals:**
- **字符级精准捕获**：基于 OCR 行级识别结合字符垂直投影分割（Projection Cut），将文本行切分为单个字符的紧凑包围盒，支持鼠标悬停磁吸与高亮提示。
- **微创局部背景修复**：仅对目标字符包围盒（外扩 1~2px）进行局部无痕背景修复，完全保留左右相邻字符的边缘原生笔画与清晰度。
- **字体样式逆向拟合**：自动提取原字符前景墨色、背景底色、字号与字体流派（黑体/宋体/楷体/等宽）。
- **友好交互微型气泡**：点击目标字直接原地弹出微型编辑气泡，自动全选原字符，支持 Tab / Shift+Tab 在行内相邻字符间极速流转修改。
- **同轴对齐与历史撤销**：新字符严格按原字符基线与可视油墨中心同轴渲染，生成矢量图元纳入 `QUndoStack` 支持无限撤销。

**Non-Goals:**
- 不引入重型深度学习超分与生成式修复模型（如 LAMA / SD），保持 100% 本地纯 C++ 算法与零额外体积。
- 不做多行段落自动重排版（Word-wrap Reflow），专注单字符/单个连续短词的原位无痕替换。

## Decisions

### 1. 字符切分与磁吸定位算法 (`CharSegmentation`)
- **决定**：基于现有已集成的 OCR（WindowsMediaOcr / RapidOCR）得到的文本行位置与字符内容，利用行内灰度二值化与**垂直投影直方图波谷探测（Vertical Projection Valleys）**，并以 OCR 字符串长度作为先验约束，切分出每个独立字符的高精包围盒。
- **对比**：纯连通域分析（Connected Components）容易将汉字左右偏旁（如“休”、“明”）误切分为两个字；OCR 字符数先验约束 + 投影波谷能精准将偏旁合并为一个完整汉字包围盒。

### 2. 微创单字符背景修复算法 (`CharInpainter`)
- **决定**：仅针对单个字符的精确 BBox 向外扩展 1~2px。采样该微小包围盒的上、下两边缘以及左/右避让区背景像素：
  - 纯色背景：直接取边界背景中值色平涂；
  - 渐变背景：执行垂直/水平双向线性插值；
  - 纹理背景：结合二值化文字笔画掩码执行局部快速 Telea 扩散修复。
- **效果**：彻底杜绝“擦除一个字，连带把左右相邻字的竖笔画或点擦掉半截”的现象。

### 3. 原文字体属性推断与同轴对齐
- **决定**：
  - **字重与流派**：统计原字符连通域水平穿越与垂直穿越厚度比（$T_v / T_h$）。当比值 $\ge 1.8$ 时智能匹配为宋体（SimSun），否则匹配黑体（Microsoft YaHei）；如果是英文字母且等宽则匹配 Consolas；
  - **对齐基准**：获取原字笔画的重心与包围盒垂直中心，新字符排版时通过 `QFontMetrics` 严格对齐基线与水平中心，确保替换后视觉上平稳同轴，无上下浮动跳跃感。

### 4. 极简用户交互流转 (`SingleCharEditor`)
- **决定**：
  - 悬停态：鼠标靠近字符时呈现轻微浅天蓝圆角半透明微光边框；
  - 单击态：直接就地激活微型输入气泡框，原字符高亮选中；下方悬浮 18px 微型工具胶囊（流派切换、粗细调节、颜色吸管）；
  - 流转热键：按下 `Enter` 保存并关闭；按下 `Tab` 自动流转至行内下一个字符并激活输入；按下 `Shift+Tab` 流转至上一个字符；按下 `Esc` 取消。

## Risks / Trade-offs

- **[紧凑排版字间距粘连风险]**：部分斜体或密集排版英文中两字笔画可能轻微重叠。
  - *缓解措施*：结合 OCR 字符等分先验与连通域骨架分析，即使波谷未落至 0 也能在极小值处切分，并微调擦除掩码只作用于油墨核心区域。
- **[特殊背景修复痕迹风险]**：
  - *缓解措施*：在输入气泡中提供“背景色吸管”与微调滑条，用户在遇到极复杂图案背景时可一秒手动校准底色。
